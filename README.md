# RealisticWorldOverhaul Minecraft Add-On

RealisticWorldOverhaul is a Minecraft Bedrock and Education Edition add-on that transforms the world into a realistic survival experience. This add-on introduces hardened tools with superior durability, realistic water physics with flowing currents and buoyancy, sprint stamina mechanics, realistic mob walk and run animations, and six new mobs that spawn naturally in their respective biomes. From the dense forests with deer to the dangerous ocean waters patrolled by sharks, every biome gains new life and challenges.

## Install

1. **Download the add-on**: Obtain the `realism.mcaddon` file from the repository releases.
2. **Import the add-on**: Double-click the `.mcaddon` file to open it with Minecraft, or manually import it through the game's settings.
3. **Enable the pack**: When creating or editing a world, navigate to Settings → Behavior Packs and Resource Packs, then activate both "Realism Pack (Behavior)" and "Realism Pack (Resources)".
4. **Enable experiments**: If prompted, enable "Beta APIs" or experiment toggles to allow scripting features.
5. **Join the world**: You should see a welcome message confirming the pack is active.

## Use

### New Mobs

Spawn new mobs using the `/summon` command:

```
/summon realism:deer
/summon realism:jaguar
/summon realism:scorpid
/summon realism:shark
/summon realism:snow_wolf
/summon realism:swamp_toad
```

### New Items

Give yourself hardened tools and materials:

```
/give @s realism:hardened_iron_ingot 8
/give @s realism:obsidian_shard 4
/give @s realism:hardened_sword
/give @s realism:hardened_pickaxe
/give @s realism:hardened_axe
/give @s realism:hardened_shovel
/give @s realism:hardened_hoe
/give @s realism:obsidian_tipped_sword
```

### Crafting

Craft new items at a crafting table:
- **Hardened Iron Ingot**: Surround coal with 8 iron ingots to get 4 hardened iron ingots.
- **Hardened Sword**: 2 hardened iron ingots vertically with a stick below.
- **Hardened Pickaxe**: 3 hardened iron ingots across the top with 2 sticks below.
- **Hardened Axe**: 2 hardened iron ingots and 2 sticks in an axe pattern.
- **Hardened Shovel**: 1 hardened iron ingot with 2 sticks below.
- **Hardened Hoe**: 2 hardened iron ingots with 2 sticks below.
- **Obsidian Shard**: Place 1 obsidian in the crafting grid to get 4 shards.
- **Obsidian-Tipped Sword**: Combine a hardened sword with an obsidian shard.

### Textures

The add-on references texture files that must be added as PNG images. Copy or generate these files:
- Resource pack textures for entities: `deer.png`, `jaguar.png`, `scorpid.png`, `shark.png`, `snow_wolf.png`, `swamp_toad.png`
- Item textures: `hardened_iron_ingot.png`, `obsidian_shard.png`, and textures for each tool
